# Jesse Mokolo — Portfolio Website

A personal portfolio website for Jesse Mokolo, a Software Engineering student and Python & AI enthusiast based in Lagos, Nigeria. Built with React, TypeScript, Tailwind CSS, and Vite.

Live at: [jessemokolo.me](https://jessemokolo.me)

---

## About

This portfolio showcases Jesse's background, technical skills, projects, and experience as a final-year Software Engineering student at Babcock University. It serves as a central hub for recruiters, collaborators, and anyone interested in Jesse's work.

---

## Features

- **Hero Section** — Introduction with links to GitHub and LinkedIn
- **About Me** — Background, education summary, and personal bio
- **Skills** — Key technical competencies displayed as visual badges
- **Projects** — Highlighted projects including UniPal, JesseBot, and Campus Exit Management System
- **Experience** — Professional experience timeline
- **Education** — Academic history and achievements
- **Certifications** — Verified certificates from Nvidia and New Horizons
- **Contact** — Email and social links for getting in touch
- **Fully Responsive** — Optimized for desktop and mobile screens
- **Smooth Animations** — Section transitions and scroll effects throughout

## Projects Highlighted

### UniPal
A RAG-driven chatbot built as a Final Year Project (2026) for Babcock University students. Helps students query university-specific information through a conversational interface powered by a Retrieval-Augmented Generation pipeline.

### JesseBot
A RAG-based Telegram chatbot designed to represent Jesse's identity, skills, and background — essentially a digital twin that can answer questions about Jesse.

### Campus Exit Management System
A digital platform that streamlines the student exeat (exit) request and approval workflow at Babcock University, replacing manual paper-based processes.
